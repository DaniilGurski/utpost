# Skuldinventering

Ögonblicksbild av den gamla appen (React + Express), skriven mot commit `2bd9623`. Radnummer och sökvägar gäller den commiten. Levande status finns i GitHub Issues, varje rad här har ett ID (`TD-xx`) som också står i titeln på motsvarande issue.

## Allvarlighetsgrad

- **Hög**: säkerhetshål, exponerade hemligheter, dataförlust eller att appen kraschar vid normal användning.
- **Medel**: fungerar, men försämrar prestanda eller underhållbarhet så mycket att det bromsar teamet eller användarna.
- **Låg**: inkonsekvens, saknad finish eller ofärdig funktion utan risk eller verklig påverkan på användare.

Passar en rad in på två nivåer väljs den högre.
