| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------ |
| Fem separata anrop på startsidan                                             | `web/src/componenents/Home.jsx` rad 13                                                      | Dålig prestanda                                                    | Medel  |
| Seed-script genererar HTML för guides                                        | `api/src/db/seed.js` rad 12                                                                 | Dålig prestanda                                                    | Låg    |
| Seeding är för svårt skriven, SQL i for-loopar                               | `api/src/db/seed.js`                                                                        | Dålig prestanda                                                    | Medel  |
| Anrop till tours-endpoint väger för mycket jämfört med andra                 | `api/src/routes/tours.js` rad 11                                                            | Dålig prestanda                                                    | Medel  |
| Config-filen i node-appen visar känslig data (connection string, JWT secret) | `api/config.js`                                                                             | Känslig data exponeras                                             | Hög    |
| Dålig README ("fråga Markus" på deployment-raden)                            | `README.md` rad 46                                                                          | Otydligt                                                           | Låg    |
| String interpolation i guide search route handler                            | `api/src/routes/guides.js` rad 22                                                           | Öppet för SQL injection                                            | Hög    |
| Ohanterade fel (typ överallt)                                                | `api/src/routes/guides.js`, `web/src/pages/GuideDetail.jsx`                                 | Appen krashar lätt                                                 | Hög    |
| Platshållare / hårdkodade pixels                                             | `api/src/routes/photos.js`                                                                  | Ofärdig implementation                                             | Låg    |
| Konstig password check                                                       | `api/src/routes/auth.js`                                                                    | Lösenord är inte ens hashade                                       | Hög    |
| `requireUser` används bara i en route                                        | `api/src/routes/tours.js` rad 37                                                            | Det finns fler känsliga routes som är oskyddade                    | Hög    |
| Inga migration tools, fast Drizzle erbjuder det                              | `api/src/db/migrate.js`                                                                     | Ingen migration historik                                           | Medel  |
| Klienten hämtar data på två olika sätt                                       | `web/src/pages/Guides.jsx` rad 9 (rå fetch), `web/src/pages/Home.jsx` rad 14 (via `api.js`) | Inkonsekvent                                                       | Låg    |
| Register-route finns, men går inte att registrera på webbsidan               | `api/routes/auth.js` rad 18                                                                 | Du kan inte använda appen om du inte använder en seeded konto      | Låg    |
| App läser localStorage utanför state                                         | `web/src/App.jsx` rad 11                                                                    | Appen kan inte reagera när token ändras                            | Låg    |
| Inga protected routes                                                        | `web/src/App.jsx` rad 11                                                                    | Användaren kan få tillgång till känsliga routes utan en token      | Låg    |
| Route handlers anger ingen response status                                   | t.ex `api/src/routes/tours.js`                                                              | Otydligt, kan skapa förvirring. De flesta responses kommer med 304 | Låg    |
